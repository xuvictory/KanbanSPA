## 用户需求

对现有 WorkBuddy 学习看板（workbuddy-learning-board.html）修复两个问题：

### 功能需求

1. **上边框高度一致**：看板列"初识 WorkBuddy"与"环境准备与界面"的上边框视觉高度不一致，需要统一所有列顶部色带的位置与高度，选中列与非选中列的上边框保持一致。
2. **按钮与内容列双向联动**：顶部阶段按钮与下方看板列严格联动，同一时间只能有一对（按钮+列）处于选中状态。点击顶部按钮时下方对应列选中；点击看板列时顶部对应按钮同步选中；切换阶段后旧的一对自动取消选中。

### 边界与约束

- 仅修改单个 HTML 文件，不改变现有数据、布局与整体视觉风格
- 保持现有滚动联动（滚动看板同步高亮按钮）行为不变
- 修复进阶看板（board-advanced）点击卡片后列高亮丢失、进度不刷新的既有 Bug

## 技术栈

- 纯前端单文件应用：原生 HTML + CSS + JavaScript（无框架、无构建工具）
- 本地存储：localStorage（进度持久化，本次不涉及修改）

## 实现方案

### 问题 1：上边框高度不一致（CSS）

根因：选中列 `.column.active-column` 用 `box-shadow: 0 0 0 3px` 在四周外扩蓝色描边，且 `transform: translateY(-2px)` 上移；同时 `.column.active-column .column-header` 用 `border-top-color: transparent !important` 隐藏顶部 3px 阶段色边框，导致选中列顶部呈现"外圈蓝框"、非选中列顶部呈现"内部色带"，两者上边框视觉高度错位。

修复策略（统一顶部呈现方式）：

1. `.column:hover` 与 `.column.active-column` 的 box-shadow 由"四周 3px"改为"左、右、下三边 3px"（`-3px 0 0 0` / `3px 0 0 0` / `0 3px 0 0`），顶部不再描边，统一由 `.column-header` 的 3px 阶段色 border-top 呈现，保证所有列顶部视觉高度完全一致
2. 移除 `.column.active-column` 的 `transform: translateY(-2px)`，避免选中列整体上移产生高度偏差
3. 删除 `.column.active-column .column-header { border-top-color: transparent !important; }` 这条 hack
4. `.column.active-column` 的描边色由固定蓝色 `var(--accent)` 改为 `var(--col-color)`，与对应阶段按钮选中色一致，强化"按钮+列成对选中"的视觉联动
5. 为可点击的 `.column-header` 增加 `cursor: pointer`，提示可交互

### 问题 2：按钮与列选中联动（JS）

现状：已有 `renderStageButtons()`（按钮 active 由当前阶段决定）、`onStageClick()`（点按钮→按钮互斥+列高亮+滚动）、`syncStageFromScroll()`（滚动停止后同步按钮与列），但缺少"点击列→按钮高亮"的反向联动；且 `toggleAdvCard()` 点击进阶看板卡片后只重建列、未刷新进度与按钮，导致列高亮丢失。

修复策略：

1. `renderBoard()` / `renderAdvancedBoard()` 渲染的 `.column-header` 增加 `onclick="onColumnClick(id)"`（header 是安全点击目标，不与卡片勾选事件冲突）
2. 新增 `onColumnClick(id)`：更新当前看板的 currentStage 状态 → 顶部按钮互斥切换 active → 调用 `highlightActiveColumn(id)`（不触发滚动，避免与滚动联动互相干扰）
3. 修复 `toggleAdvCard()`：末尾补充调用 `updateAdvancedProgress()`（内部会刷新按钮计数并重新应用列高亮），与 beginner 侧 `toggleCard()` 的行为对齐

## 实施注意

- 联动状态收敛在 `currentBeginnerStage` / `currentAdvancedStage` + 全局清除逻辑：`highlightActiveColumn()` 已先清除两个看板所有列的 active-column，保证全局同时只有一对选中，无需额外状态管理
- 不触碰 `syncStageFromScroll` 的防抖逻辑，保持滚动同步行为不变
- 不改动任何数据结构、卡片渲染与进度存储逻辑，爆炸半径仅限选中态样式与两处 JS 函数

## 架构设计

单文件页面，无需新增模块。改动集中在：

- `<style>` 中 `.column` / `.column-header` / `.column.active-column` 相关规则
- `<script>` 中 `renderBoard` / `renderAdvancedBoard` / `toggleAdvCard` / `onColumnClick`（新增）
